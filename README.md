# YaM — Яндекс Музыка для Volumio

YaM — плагин музыкального сервиса для [Volumio](https://volumio.com/), который подключает каталог Яндекс Музыки к музыкальному проигрывателю. Он поддерживает поиск, прослушивание альбомов и плейлистов, радиостанции и воспроизведение через MPD. В режиме высокого качества YaM использует локальный прокси на свободном порту, поэтому может работать одновременно с оригинальным плагином.

Для работы нужна подписка Яндекс Музыки и устройство с установленным Volumio. YaM имеет отдельный идентификатор `yam`, поэтому его можно использовать одновременно с оригинальным плагином `yandex_music`.

YaM — форк плагина [Yandex Music для Volumio](https://github.com/achechulin/volumio-plugins-sources/tree/master/yandex_music). Спасибо автору оригинального плагина за проделанную работу и основу проекта.

## Установка из GitHub

1. Включите SSH в настройках Volumio и подключитесь к устройству.
2. Выполните команды:

```sh
cd /home/volumio
git clone https://github.com/GorINIch73/YaM.git
cd YaM
volumio plugin install
```

3. Дождитесь сообщения об успешной установке. Если Volumio предложит включить плагин, подтвердите.
4. В веб-интерфейсе Volumio откройте **Plugins → Installed plugins** и включите **YaM**.
5. Откройте настройки YaM и войдите в аккаунт Яндекс Музыки по логину и паролю либо укажите OAuth-токен.

Команда установки запускается из каталога клонированного репозитория. Volumio установит зависимости из `package.json`.

## Обновление

Подключитесь по SSH и выполните:

```sh
cd /home/volumio/YaM
git pull
volumio plugin update
sudo systemctl restart volumio
```

## Лайки

Отображение уже поставленных лайков и отправка нового лайка в аккаунт Яндекс Музыки — два разных процесса. Для отображения YaM получает список лайков аккаунта, сопоставляет ID треков с элементами каталога и очереди Volumio и передаёт отметку вместе с исходным элементом трека. Во время воспроизведения сам аудиопоток идёт через MPD, поэтому его временный URL нельзя использовать вместо ID трека Яндекс Музыки.

Установка нового лайка из плеера Volumio сложнее: интерфейс может передать плагину MPD URI текущего потока, а не исходный URI и ID Яндекс Музыки. Плагин должен восстановить исходный ID, отправить запрос авторизованному API Яндекса и затем согласовать результат с состоянием очереди и интерфейса Volumio. Поэтому лайк может появиться в плеере раньше, чем подтвердится в аккаунте, или остаться несинхронизированным. Текущая отправка запроса не гарантирует подтверждение и последующую сверку с аккаунтом.

Возможные улучшения:

- Сохранять исходный ID Яндекс Музыки в элементе очереди и использовать его для всех действий с текущим треком.
- После запроса лайка перечитывать статус трека из API Яндекса и показывать в плагине подтверждённый результат.
- При временной сетевой ошибке сохранять операцию в очереди повторов и отправлять её позже; повторять только идемпотентные операции.
- Периодически сверять локальное состояние с аккаунтом, чтобы исправлять пропущенные изменения.
- Добавить журнал с ID трека, результатом API и результатом сверки, чтобы было видно, принят ли лайк аккаунтом.
